# Gramline identity

`Gramline.png` is the transparent raster master. A continuous white G ends in a speech-bubble tail on an indigo, violet and blue macOS tile. It is an independent identity, not an Instagram or Meta logo.

Created with the built-in image generation tool on 2026-11-06. No CLI or API-key workflow was used. `script/build_icon.sh` preserves alpha and exports standard 16–1024 pixel macOS representations into `.build/Gramline.icns`. The Dock, About panel, login screen and README use the same identity.

## Generation prompt

Use case: logo-brand. Asset: the finished Dock icon for Gramline, a native macOS Instagram messaging app. Create a fresh, distinctive logo: a bold continuous white ribbon forming an open geometric capital G, with its lower terminal becoming a small speech-bubble tail. The single G/chat symbol is unmistakable and readable at 32 pixels. Center it on an elegant deep indigo macOS squircle tile with a restrained violet-to-electric-blue gradient and very subtle dimensional lighting. The symbol is clean, sculpted and mostly flat, not ornate. One centered front-facing icon only, no perspective, no scene or mockup. Square canvas, normal macOS icon padding: tile occupies about 84% of the image. The area outside the rounded tile is genuinely transparent with a restrained soft shadow. Crisp smooth edges. No wordmark, no small text, no extra objects, no Instagram camera, no Telegram paper plane, no decorative sparkles. Premium, calm and polished. Suitable as the actual application icon, not a design presentation.

The tool returned a 1254 × 1254 RGBA master. Icon packaging resamples it without changing the artwork.
